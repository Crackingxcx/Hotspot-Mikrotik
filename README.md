<h2>📌 Deskripsi Proyek</h2>
<p>
Repository ini berisi proyek pembuatan tampilan login hotspot Mikrotik yang dikembangkan sebagai bagian dari
<b>Ujian Kompetensi Kejuruan (UKK)</b> di SMK sebagai salah satu syarat kelulusan.
Proyek ini berfokus pada perancangan antarmuka login hotspot yang menarik, responsif, dan mudah digunakan oleh pengguna jaringan.
</p>

<p>
Dalam proses pengembangannya, tampilan login hotspot ini juga dibantu oleh teknologi <b>AI</b> untuk membantu
desain dan penulisan kode agar lebih efisien dan modern.
</p>

<h2>🎯 Tujuan Proyek</h2>
<ul>
  <li>Membuat tampilan login hotspot Mikrotik yang profesional dan user-friendly</li>
  <li>Menerapkan kemampuan desain web dan konfigurasi jaringan</li>
  <li>Menjadi bukti kompetensi keahlian di bidang jaringan komputer sebagai syarat kelulusan SMK</li>
</ul>

<h2>🚀 Teknologi yang Digunakan</h2>
<ul>
  <li>HTML, CSS, JavaScript</li>
  <li>Mikrotik Hotspot</li>
  <li>AI Assistance untuk desain dan pengembangan</li>
</ul>
